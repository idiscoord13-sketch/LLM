# «عروض‌یار» — موتور تقطیع و تشخیص وزن شعر فارسی (MVP اعتبارسنجی)

> وضعیت: نسخه‌ی اول کار می‌کند (بدون GPU، بدون LLM). اعداد دقت پایین همه **اندازه‌گیری‌شده** روی شعرهایی است که موتور ندیده؛
> اعداد بازار از منابع عمومی‌اند و دقیق نیستند (منبع کنارشان آمده).

## ۱. مسئله و مشتری
- درس «علوم و فنون ادبی» (رشته‌ی انسانی) بخش «موسیقی شعر» دارد: تقطیع هجایی، وزن، اختیارات شاعری، قافیه و ردیف.
  سؤال‌های امتحان نهایی و کنکور از همین بخش می‌آید ([نمونه‌سؤال‌های نهایی ۱۴۰۰–۱۴۰۴](https://gama.ir/test/detail/153304/)).
- از کنکور ۱۴۰۵، سوابق تحصیلی ۶۰٪ نمره است و پایه‌ی دوازدهم حدود ۴۳٪ ([ای‌استخدام](https://www.e-estekhdam.com/%d8%aa%d8%a7%d8%ab%db%8c%d8%b1-%d8%b3%d9%88%d8%a7%d8%a8%d9%82-%d8%aa%d8%ad%d8%b5%db%8c%d9%84%db%8c-%d8%af%d8%b1-%da%a9%d9%86%da%a9%d9%88%d8%b1-%db%b1%db%b4%db%b0%db%b5-%d8%a7%d9%81%d8%b2%d8%a7)؛ با اطلاعیه‌ی رسمی سنجش چک شود)
  ← امتحان نهایی **تشریحی** مهم‌تر شده و دانش‌آموز باید تقطیع را خودش بنویسد.
- اندازه: ۲۹۰٬۳۸۳ داوطلب گروه علوم انسانی در نوبت اول کنکور ۱۴۰۴ ([تعادل](https://www.taadolnewspaper.ir/fa/news/341629/)).
- رقبا: در جست‌وجو ابزار فارسیِ «تقطیع خودکار» پیدا نشد (فقط یک [ابزار عربی](https://adabworld.com/tools/taqti)). پیش از سرمایه‌گذاری،
  کافه‌بازار و مایکت را دستی بگرد.

## ۲. جدول چهار اقدام (اقیانوس آبی)
| حذف | کاهش | افزایش | خلق |
|---|---|---|---|
| چت عمومی | هزینه‌ی معلم خصوصی، وابستگی به اینترنت خارجی | دقت روی یک درس سخت، توضیح گام‌به‌گام | تقطیع فوری هر بیت؛ تمرین نامحدود با جواب قابل‌تأیید؛ تشخیص خطای خود دانش‌آموز |

**مشتری‌های غیرمشتری:** دانش‌آموزانی که سؤال‌های عروض را رها می‌کنند چون سخت است.

## ۳. مدل درآمد (فرضیه — باید با پیش‌فروش ثابت شود)
1. **B2B (اصلی):** موتور و API برای مؤسسه‌های کنکور، ناشران کمک‌آموزشی و پلتفرم‌ها (مثل گاما که جلسه‌های این درس را حدود
   ۲۳ تا ۳۰ هزار تومان می‌فروشد — [گاما](https://gama.ir/course/detail/125)). قیمت سالانه یا به‌ازای هر دانش‌آموز.
2. **معلم‌ها:** اشتراک ارزان برای ساختن برگه‌ی تمرین و تصحیح.
3. **B2C فریمیوم:** ربات بله/تلگرام؛ رایگان تا چند بیت در روز، اشتراک برای تمرین و توضیح.

حساب سرانگشتی (فرض، نه داده): ۵٪ داوطلبان انسانی × ۲۰۰ هزار تومان در سال ≈ ۲٫۹ میلیارد تومان. یعنی B2C به‌تنهایی کوچک است؛
رشد از B2B و گسترش به **آرایه، قافیه، قرابت معنایی** (کل درس، و ادبیات عمومیِ همه‌ی رشته‌ها) می‌آید.

## ۴. مزیت فنی (خندق)
- **واژه‌نامه‌ی وزن، خودکار از گنجور:** از ۱۱۱ هزار مصراعِ برچسب‌دار، الگوی هجای هر واژه یاد گرفته می‌شود (`myllm.aruz.lexicon`).
- **جست‌وجوی محدود به وزن:** همه‌ی صورت‌های مجاز هر بحر با اختیارات وزنی از قبل ساخته می‌شود و خوانش‌های ناممکن همان وسط مصراع هرس می‌شوند.
- **قابل‌توضیح:** خروجی، تقطیع، ارکان و اختیارات (حذف همزه، تسکین، ابدال، قلب، فاعلاتن به جای فعلاتن، بلندخوانی مصوت) را نشان می‌دهد —
  همان چیزی که امتحان می‌خواهد.
- **آفلاین و ارزان:** روی یک لپ‌تاپ معمولی، هر بیت حدود ۰٫۲ ثانیه.

## ۵. دقت اندازه‌گیری‌شده

### آزمون اصلی: ۱۲ شاعری که موتور هرگز ندیده (نسخه‌ی ۲)
عطار، سنایی، جامی، عراقی، خواجو، وحشی، شهریار، صائب، رهی، فروغی، هاتف، انوری — هیچ‌کدام در یادگیری قواعد یا واژه‌نامه نبوده‌اند
(واژه‌نامه فقط از حافظ، سعدی، فردوسی، مولوی، نظامی، خیام و پروین یاد گرفته شده). نمونه‌گیری لایه‌ای: حداکثر ۴۰ نمونه از هر بحر.

| تنظیم | واحد | n | دقت (CI ۹۵٪) | میانگین بحرها | خط پایه (اکثریت) |
|---|---|---|---|---|---|
| فقط قاعده | بیت | 866 | 0.858 [0.833, 0.879] | 0.856 | 0.046 |
| فقط قاعده | شعر (۳ بیت) | 490 | 0.918 [0.894, 0.941] | 0.949 | 0.082 |
| قاعده + واژه‌نامه v2 | مصراع | 958 | 0.848 [0.824, 0.868] | 0.847 | 0.042 |
| **قاعده + واژه‌نامه v2** | **بیت** | 866 | **0.920** [0.901, 0.938] | 0.925 | 0.046 |
| **قاعده + واژه‌نامه v2** | **شعر (۳ بیت)** | 490 | **0.976** [0.961, 0.988] | **0.982** | 0.082 |

- **واژه‌نامه‌ی v2:** ۸۵۱۴ واژه، خودکار از ۲۲٬۳۸۷ مصراعِ قابل‌استفاده (۴۵ هزار نمونه، حداکثر ۲۵۰۰ از هر بحر، دو دور EM).
- **اطمینان:** ۸۸٪ بیت‌ها «اطمینان بالا» می‌گیرند و از آن‌ها ۹۶٪ درست است؛ در حالت شعر، ۹۹٪ موارد «بالا» با ۹۸٪ درستی.
- **به تفکیک شاعر (شعر ۳ بیتی):** عراقی، جامی، خواجو، رهی، سنایی و وحشی ۱۰۰٪؛ هاتف ۹۸٪، عطار ۹۷٪، شهریار ۹۶٪، انوری ۹۵٪، فروغی ۹۴٪.
- **پیام محصولی:** از کاربر بخواه «چند بیت» بفرستد — خطا از ۸٪ (یک بیت) به ۲٫۴٪ (سه بیت) می‌رسد.

### آزمون قبلی (نسخه‌ی ۱): شعرهای کنارگذاشته‌ی همان ۷ شاعر
شعرهای ارزیابی (۲۰٪ شعرها، جدا بر اساس شعر) هرگز در یادگیری واژه‌نامه دیده نشده‌اند. نمونه‌گیری لایه‌ای بر اساس بحر
(وگرنه شاهنامه نصف نمونه می‌شد). اجرا: `python scripts/eval_aruz.py [--couplets | --poem-couplets 3] [--lexicon ...]`.

| تنظیم | واحد | n | دقت (CI ۹۵٪) | میانگین بحرها | خط پایه (اکثریت) |
|---|---|---|---|---|---|
| فقط قاعده | مصراع | 866 | **0.740** [0.710, 0.768] | 0.755 | 0.046 |
| فقط قاعده | بیت | 749 | **0.814** [0.785, 0.841] | 0.834 | 0.053 |
| قاعده + واژه‌نامه‌ی گنجور | مصراع | 866 | **0.880** [0.858, 0.901] | 0.888 | 0.046 |
| قاعده + واژه‌نامه‌ی گنجور | بیت | 749 | **0.919** [0.899, 0.937] | 0.935 | 0.053 |

- **واژه‌نامه** (۵۷۱۱ واژه، خودکار از ۱۷٬۳۷۲ مصراعِ شعرهای آموزشی) خطای بیت را از ۱۸٫۶٪ به ۸٫۱٪ رساند — بیش از نصف خطاها حذف شد.
- **اطمینان قابل‌اتکاست:** با واژه‌نامه، ۹۰٪ بیت‌ها «اطمینان بالا» می‌گیرند و از آن‌ها **۹۵٪** درست است (۶۷۳ بیت)؛
  سطل «پایین» فقط ۴۰٪ درست است → در محصول، زیر «متوسط» بگو «مطمئن نیستم» و گزینه‌ی دوم را هم نشان بده.
- **به تفکیک شاعر (بیت):** سعدی ۹۶٪، مولوی ۹۷٪، حافظ ۹۳٪، فردوسی ۹۲٪، خیام ۹۰٪، پروین ۸۹٪، نظامی ۸۹٪.
- **قافیه و ردیف:** ۸۹٫۰٪ تطابق دقیق با «حروف قافیه + ردیف» گنجور روی ۵۰۰ غزل حافظ و سعدی.
- **خطاهای شناخته‌شده:** مصراع‌های عربی (ایها الساقی…)، تشدید نانوشته (طرّه)، و بحرهای هم‌خانواده که فقط در رکن پایانی فرق دارند
  (رمل مثمن محذوف/سالم، مجتث مخبون محذوف/سالم). ضعیف‌ترین بحرها با واژه‌نامه: هزج مسدس محذوف ۷۸٪، هزج مسدس اخرب مقبوض ۸۲٪،
  خفیف ۸۵٪. هدف «≥ ۹۰٪ در حالت بیت» از نظر کل برآورده شد (۹۱٫۹٪؛ حد پایین CI ۸۹٫۹٪)، ولی برای این سه بحر هنوز نه.

> هشدار: ارزیابی بر برچسب وزن گنجور تکیه دارد، نه بر تقطیع هجا‌به‌هجای یک متخصص. قبل از فروش، ۱۰۰ بیت از کتاب درسی را
> یک دبیر ادبیات با خروجی موتور مقایسه کند (دقت تقطیع، نه فقط نام بحر).

## ۶. اعتبارسنجی بازار در ۲ تا ۴ هفته
1. ربات را روی بله و تلگرام بالا بیاور (پایین را ببین) و لینک را به ۲۰ دانش‌آموز انسانی بده. معیار: چند نفر بعد از یک هفته هنوز استفاده می‌کنند؟
2. **۱۰ دبیر ادبیات** و **۳ تا ۵ مؤسسه/ناشر** را ببین. اسکریپت مصاحبه:
   - «تقطیع را الان چطور درس می‌دهید/تصحیح می‌کنید؟ سخت‌ترین قسمتش برای دانش‌آموز چیست؟»
   - «آخرین باری که برای این درس پول خرج کردید (کتاب، کلاس، آزمون) چه بود و چقدر؟»
   - (بعد از دمو) «اگر این را با اسم خودتان در اپ‌تان داشتید، چه چیزی باید اضافه شود تا بخرید؟»
   - «حاضرید الان یک پیش‌پرداخت کوچک برای نسخه‌ی کامل بدهید؟» ← تنها جوابی که ارزش دارد.
3. معیار ادامه: حداقل **یک پیش‌پرداخت B2B** یا **۵۰ پرداخت B2C**. اگر نشد، به ایده‌ی بعدی برو (هزینه‌ی از دست‌رفته: چند هفته، نه چند ماه).

## ۷. اجرا
```bash
# داده (روی سیستم خودت؛ فقط برای استفاده‌ی محلی — لایسنس داده‌ی گنجور را بپرس)
uv run python -m myllm.aruz.ganjoor download --cat /hafez/ghazal --max-poems 500
uv run python -m myllm.aruz.ganjoor download --cat /saadi/divan/ghazals --max-poems 700
uv run python -m myllm.aruz.ganjoor download --cat /ferdousi/shahname --max-poems 300
uv run python -m myllm.aruz.ganjoor download --cat /moulavi/shams/ghazalsh --max-poems 400
# (برای نسخه‌ی v2 این‌ها هم: /moulavi/masnavi/daftar1، /nezami/5ganj، /khayyam/robaee، /saadi/boostan، /parvin/divanp، /moulavi/shams/robaeesh)
# واژه‌نامه (حدود ۱٫۵ ساعت روی CPU؛ تنظیمات نسخه‌ی v2)
uv run python -m myllm.aruz.lexicon learn --max-hemistichs 45000 --per-meter-cap 2500 --iterations 2 --out data/processed/aruz_lexicon.json
# ارزیابی روی شاعران تازه
uv run python -m myllm.aruz.ganjoor download --cat /attar --max-poems 80 --out data/raw/ganjoor_newpoets   # و بقیه‌ی ۱۲ شاعر
uv run python scripts/eval_aruz.py --root data/raw/ganjoor_newpoets --holdout 1.0 --poem-couplets 3 --lexicon data/processed/aruz_lexicon.json
# تست دستی
uv run python -m myllm.aruz.scan "بشنو این نی چون شکایت می‌کند" "از جدایی‌ها حکایت می‌کند" --lexicon data/processed/aruz_lexicon.json
uv run python -m myllm.aruz.bot --repl
# ربات (توکن از BotFather در تلگرام یا بازوساز بله)
ARUZ_BOT_TOKEN=... uv run python -m myllm.aruz.bot --platform bale
```

## ۸. بعد از اثبات تقاضا
- **آرایه‌ها:** گنجور برچسب آرایه‌های ادبی دارد (`literary-devices.json` و `LiteraryTags` هر شعر) ← داده‌ی آموزش و ارزیابی برای «تشخیص آرایه».
- **LLM:** SFT روی Qwen3-1.7B/4B برای توضیح به زبان ساده و ساخت سؤال تمرینی با جواب قابل‌تأیید؛ GRPO با پاداش «وزن درست» از همین موتور
  (`myllm.train.rewards` + `myllm.aruz.scan`).
- **حقوقی:** قبل از فروش، مجوز استفاده‌ی تجاری از داده‌ی گنجور را بگیر یا واژه‌نامه را از متن‌های آزاد/خودساخته بساز.
