# «ادب‌یار» — راهبرد اقیانوس آبی: از «ربات وزن‌یاب» به «زیرساخت هوش ادبی فارسی»

> خلاصه: رقیبان یا **کتاب و کلاس**‌اند (گران، کند، بی‌بازخورد) یا **چت‌بات‌های عمومی** (وزن و تقطیع را با اطمینان غلط می‌گویند).
> ما سومی هستیم: موتور **قاعده‌محورِ توضیح‌پذیر با دقتِ سنجیده**، که روی CPU اجرا می‌شود و برای هر خطا «چرا»ی کتابی می‌دهد.
> این موتور در چهار شکل فروخته می‌شود: ربات دانش‌آموز، ابزار دبیر، مجوز آموزشگاه و API ناشر.

## ۲. جدول چهار اقدام (در سطح پلتفرم)
- **حذف:** حفظ‌کردنِ کورِ جدول بحرها؛ وابستگی به معلم خصوصی برای تصحیح تقطیع؛ تایپ دستی سؤال توسط دبیر؛ هزینه‌ی GPU و LLM برای هر درخواست.
- **کاهش:** هزینه‌ی کلاس عروض، زمان ساخت آزمون (از چند ساعت به یک دقیقه)، فاصله‌ی «اشتباه کردم» تا «فهمیدم چرا».
- **افزایش:** توضیح قاعده‌ایِ هر خطا، شفافیت دقت (عدد با بازه‌ی اطمینان و آزمون دست‌نخورده)، شخصی‌سازی و حریم خصوصی.
- **ایجاد:** کارنامه‌ی خطای *قاعده‌محور* (نه فقط نمره)، آزمون ضدتقلب چندنسخه‌ای، API ادبی فارسی برای ناشران، و داده‌ی خطای دانش‌آموزان
  که چرخ‌طیار بهبود محصول است.

## ۴. خندق: چرا کپی‌کردنش سخت است
1. **توضیح‌پذیری قاعده‌ای:** هر خطا یک `rule` دارد (`RULES` در `diagnose.py`). چت‌بات عمومی نمی‌تواند با اطمینان بگوید «ن» پس از
   مصوت بلند حساب نمی‌شود *و* همان را درست اعمال کند.
2. **دقتِ سنجیده و منتشرشده:** آزمون روی شاعرانی که موتور ندیده، یک آزمون نهایی دست‌نخورده (test2)، و برگه‌های داوری انسانی.
   ادعایی بدون عدد نمی‌کنیم. این خودش اعتماد ناشر را می‌خرد.
3. **چرخ‌طیار داده:** آمار ناشناسِ «کدام قاعده بیشتر جا می‌افتد»، با رضایت کاربر و فقط شمارش، هم نکته‌ها را بهتر می‌کند و هم دشواری
   آزمون‌ها را تنظیم می‌کند. هیچ رقیبی این داده را ندارد.
4. **هزینه‌ی نزدیک به صفر برای هر درخواست:** همه روی CPU اجرا می‌شود و هزینه‌ی GPU یا API ندارد، پس می‌توانیم ارزان‌تر از هر محصولِ
   متکی به LLM بفروشیم.
5. **فهرست مرجع راستی‌آزمایی‌شده** برای تاریخ ادبیات، به‌جای اعتماد به عنوان‌های منسوب.
6. **کانال توزیع:** ربات بله و تلگرام بدون نصب، و شبکه‌ی دبیران از طریق آزمون‌ساز رایگان (lead magnet).

## ۵. برنامه‌ی ۹۰ روزه
- **هفته‌ی ۱ و ۲:** راه‌اندازی ربات روی بله (اصلی) و تلگرام، و ۱۰ مصاحبه با دبیر (پرسش‌نامه در `aruz.md` §۶).
- **هفته‌ی ۳ و ۴:** آزمون‌ساز رایگان برای ۲۰ دبیر و جمع‌آوری بازخورد درباره‌ی کیفیت سؤال‌ها.
- **ماه ۲:** طرح آزمایشی با ۲ آموزشگاه کنکور (طرح `school`) با کارنامه‌ی کلاس.
- **ماه ۳:** کلید آزمایشی API برای ۲ ناشر کمک‌آموزشی و مذاکره‌ی قیمت به ازای مصرف.
- **سنجه‌ها:** کاربر فعال هفتگی، `/check` به ازای هر کاربر، ماندگاری روز هفتم، آزمون ساخته‌شده توسط دبیرها، نرخ تبدیل به پولی، و تماس‌های API.

## ۷. گسترش بعدی (به ترتیب ارزش)
1. **برچسب‌زن LLM برای آرایه‌های معنایی** (استعاره، کنایه، مجاز، ایهام) با QLoRA روی Qwen3 روی 4060، با سنجش P/R روی شعرهای کنارگذاشته.
2. **ویرایشگر وزن برای شاعر:** هنگام نوشتن، هجای ناجور را نشان می‌دهد و واژه‌ی هم‌وزن و قافیه پیشنهاد می‌کند.
3. **خوانش عروضی صوتی:** شعر با کشش‌های درستِ وزن خوانده می‌شود (TTS).
4. **OCR صفحه‌ی کتاب درسی:** عکس صفحه گرفته می‌شود و تقطیع و آرایه برمی‌گردد.
5. **بازار فارسی‌زبانِ بیرون از ایران:** افغانستان، و تاجیکستان با پشتیبانی از خط سیریلیک.
