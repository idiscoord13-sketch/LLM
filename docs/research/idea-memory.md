# ایده‌ی ۱۳-۶ — Memory→Weights Promotion Ladder (فقط طراحی)

**مسئله:** چه دانشی در RAG/memory بماند و چه چیزی در وزن‌ها «جا بیفتد»؟
**طراحی:** هر آیتم memory شمارنده‌ی «استفاده‌ی موفق» و «اعتبارسنجی» دارد؛ آیتم‌هایی که از آستانه گذشتند و با eval سازگارند به داده‌ی SFT
تبدیل می‌شوند → تقطیر دوره‌ای فقط روی آیتم‌های تثبیت‌شده → regression gate؛ شکست = برگشت به memory.
**پیش‌نیاز:** سیستم memory بلندمدت (vector store) در gateway — بعد از پایدار شدن فاز ۵. قانون تا آن موقع:
حقیقت‌ها با RAG، رفتار با fine-tune، ترجیح شخصی در memory (سند §۷.۵).
